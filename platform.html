API

Ingest Events

POST /api/events
Content-Type: application/json

{
  "event_type": "governance_check",
  "category": "agent_welfare",
  "result": "pass",
  "details": "Agent stress below threshold"
}

Get Scores

GET /scores

  "overall_grade": "A+",
  "overall_score": 99.7,
